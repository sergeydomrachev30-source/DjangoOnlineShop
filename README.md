# Django Online Store

Проект представляет собой веб-приложение для интернет-магазина, разработанное на фреймворке Django в рамках учебного курса.

## Функциональность проекта
- **Каталог товаров**: Созданы полноценные связанные модели товаров (`Product`) и категорий (`Category`).
- **Архитектура шаблонов**: Реализован единый базовый шаблон (`base.html`) со сквозной навигацией, от которого наследуются все страницы проекта для исключения дублирования кода.
- **Главная страница**: Отображает полный список товаров из базы данных с использованием оптимизированного ORM-запроса `Product.objects.all()`. Реализована обрезка длинных описаний в карточках до 100 символов с помощью встроенных фильтров Django.
- **Постраничная навигация (Пагинация)**: Реализован постраничный вывод списка товаров на главной странице (лимит — 2 товара на страницу) с удобными кнопками переключения «Назад» и «Вперед».
- **Детальная страница товара**: Создан контроллер для динамических URL-адресов вида `/products/<int:pk>/` с использованием безопасного извлечения объектов через `get_object_or_404`. Страница выводит полную информацию о продукте и кнопку возврата в каталог.
- **Добавление товаров**: Реализована защищенная страница с формой для создания новых товаров пользователем, включая поддержку загрузки изображений (`enctype="multipart/form-data"`), валидацию полей и автоматическое сохранение в БД с последующим редиректом.
- **Страница контактов**: Контактная информация динамически подгружается из базы данных (управляется через админку).
- **Обратная связь**: Форма отправки сообщений (обработка POST-запросов) с защитой от CSRF-атак, валидацией обязательных полей на стороне сервера и выводом уведомления об успешной отправке.
- **Панель администратора**: Настроено продвинутое отображение списков, добавлены фильтры по категориям и поиск по названию/описанию.

## Стек технологий
- Python 3.14+
- Django 6.0.5+
- PostgreSQL (драйвер `psycopg2-binary`)
- Pillow (для работы с медиаданными)
- Python-dotenv (сокрытие чувствительных данных)
- IPython (интерактивная оболочка shell)
- Bootstrap 5

## Локальный запуск проекта

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_ваш_репозиторий>
cd DjangoOnlineStoreProject
```

### 2. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv

# Для Windows:
venv\Scripts\activate

# Для macOS/Linux:
source venv/bin/activate
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге проекта на основе шаблона и заполните своими данными для подключения к PostgreSQL:
```text
DB_NAME=django_shop
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Применение миграций
```bash
python manage.py migrate
```

### 6. Заполнение базы данных тестовыми данными
Для автоматической очистки базы данных и загрузки демонстрационных категорий и товаров из фикстур выполните команду:
```bash
python manage.py fill_db
```

### 7. Запуск сервера разработки
```bash
python manage.py runserver
```
После запуска проект будет доступен в браузере по адресу: http://127.0.0

## Правила ведения разработки (GitFlow)
Разработка проекта ведётся по методологии GitFlow:
- main — стабильная ветка с релизной версией проекта.
- develop — основная ветка разработки, куда сливаются готовые домашние задания.
- feature/ — отдельные ветки под конкретные задачи и домашние задания (например, feature/homework-1).
